## Code

- Scene composition uses `three`, `@react-three/fiber`, `@react-three/drei`
  (MIT, already project dependencies). No other external code was copied.
- No network HDRs/presets: studio lighting is fully procedural
  (`<Lightformer>` softboxes rendered into a 256px environment map).

## Custom-garment hollow shell (silhouette.ts)

- **Technique:** discrete Poisson inflation (∇²h = −4, red–black SOR) after
  Ilya Baran & Jaakko Lehtinen, "Notes on Inflating Curves" (2009),
  https://people.csail.mit.edu/ibaran/papers/inflate.pdf — method
  reimplemented from the paper's description; no code copied.
- All other geometry/shading code (seam remap, linings, photo-wrinkle normal
  map, drape folds) written for this project. No external assets.
